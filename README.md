# Primeiro Site em Flask

Este é meu **primeiro projeto com Flask**, criado com o objetivo de aprender os fundamentos de desenvolvimento web em Python.  
O projeto consiste em um site simples com páginas HTML, rotas no Flask e estilização básica com CSS.

---

##  Tecnologias utilizadas

- Python
- Flask
- HTML
- CSS

---

## ▶️ Como rodar o projeto localmente

1. clone o repositório:
bash
git clone
https://github.com/Fabiosilva-dev-Meu-primeiro-site.git

2.Entre na pasta do projeto:

cd meu-primeiro-site

3.Crie um ambiente virtual:

python -m venv venv

4.Ative o ambiente virtual(Windows):

source venv/bin/activate

4.Ative o ambiente virtual(Linux/Mac):

source venv/bin/activate

5.Instale as dependencias:

pip install Flask

6.Execute a aplicação:

python app.py

7.Abra o navegador:

https://127.0.0.1:500
